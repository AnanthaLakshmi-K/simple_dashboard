GETTING STARTED (5 MINUTES)
================================================================================

1. Install .NET 8 SDK
   → https://dotnet.microsoft.com/download/dotnet/8.0

2. Create Blazor Project
   → dotnet new blazor -n AIAssistantSalesOperationsDashboard -f net8.0

3. Install Syncfusion
   → dotnet add package Syncfusion.Blazor.Grids --version 25.1.34
   → (Plus 8 more packages - see QUICK_START.md)

4. Copy Source Files
   → Copy all files from this committed repository

5. Run Application
   → dotnet run
   → Opens at https://localhost:7201
